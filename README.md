# MEGA X

پلتفرم ابزارهای مرورگرمحور پریمیوم — فقط برای GitHub Pages.

## ویژگی‌ها

- طراحی تاریک پریمیوم با گرادیان و glow کنترل‌شده
- پشتیبانی کامل RTL و فارسی
- ابزار متن، هش (SHA-256 + MD5)، QR، تحلیل URL، متن‌به‌گفتار
- موسیقی: جستجوی محلی + لینک به سرویس‌های معتبر
- همه داده فقط در localStorage مرورگر
- بدون بک‌اند، بدون کلید مخفی

## اجرا

فقط فایل‌ها را روی GitHub Pages سرو کن. نیاز به build نیست.

```
https://commander1405.github.io/mega-x/
```

```
index.html
```

## محدودیت‌ها (صادقانه)

- جستجوی زنده موسیقی از APIهای کلیددار ممکن نیست
- اسکرین‌شات وب‌سایت و HTTP status واقعی بدون سرور ممکن نیست
- GIF ویدیو به ویدیو نیاز به encoder سنگین دارد و در این نسخه پیاده نشده
